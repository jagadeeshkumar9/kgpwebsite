Platform

One platform, multiple applications

MQTT live telemetry, device health, alerts, trends, statistics, remote controls, auto/manual operation and multi-device monitoring — all in a single unified console.

Core capabilities

What the console gives an operator

Real-time MQTT

Live device status and telemetry over MQTT/WebSocket — readings update as they happen, not on a polling delay.

Device health

Online/offline state and last-seen monitoring for every connected device, at a glance.

Alerts

Threshold and warning-condition visibility so out-of-range readings surface immediately.

Analytics

History charts with current, minimum, maximum and average values over a chosen window.

Remote control

Send device-specific operating commands — start a pump, open a gate, switch a light — from the console.

Auto / manual

Application-specific operating modes, switchable per device without touching the hardware.

Restart

Remote restart command where the device supports it, for fast recovery without a site visit.

Multi-device

Multiple device instances organized by class, so one console scales from a single site to many.
